## Communicate

### Reflections

I learned how stressful and complicated this kind of analysis can be on a computer and on the human brain. Running this analysis was frustrating, much like dealing with a printer that won't print correctly. The process to get these analyses was complicated and not as accurate as I would've liked them to be, as I used Creo instead of SolidWorks, which has a built-in feature that can run these kinds of analyses with more explanatory steps similar to what the professor demonstrated to us in class over what Creo displayed. Overall, I didn't like the process of capturing these results, as I had troubles coordinating Creo's simulation addition to the main program. But in the end, I achieved not just 3 but 4 test results.

Time spent: 3.5 to 4 hours.
