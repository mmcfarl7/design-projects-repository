## Decide
### Drawing

When creating the drawing of this bracket, I first had to model it in Creo. Using inches and default Creo settings I was able to create my model as shown below. I was once again shocked by the engineering behind the model. It was rather questionable in appearance with the biggest red flag being the bar in between the strap cylinder and the slot where the T-bar is supposed to go. It was quite thin and I questioned the structure of the design, but the math was flawless and it backed up the model. Ergo, once again I learned that math doesn't make things pretty, it makes things functional.

## Communicate
### Final Reflection and Resources

All in all, the assignment was fairly difficult as was the last one where I had to go back and reference specific rules for the dimensions of the model. I decided that if the tolerance block was going to be included the looser the tolerance the less important the feature. Stiffness was a key measure in what drove the dimensions (as referenced in A05) such as feature 2, the flange between the cylindrical bar and the T-Bar slider. If I was to include a tolerance on that bar it would've stated, you cannot go less than the dimension number but way over the limit is acceptable. If I was to change one thing about this project I would've wished I made the part larger or I would've changed the material, maybe then I would trust the appearance of the part more, then again appearances are decieving. The math proves this part is functional, but appearances suggest otherwise. Sometimes it's tough being an engineer.
